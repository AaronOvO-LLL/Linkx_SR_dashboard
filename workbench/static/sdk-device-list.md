# SDK 可对接设备清单

> 更新时间：2026-06-30

详见文档：[查看完整接入文档](https://drive.weixin.qq.com/s?k=ANEA8AehABArCpjkbv)

## 6.3 SDK 接入

SDK 接入目前支持海康、大华、宇视三个厂家的 NVR、CVR、IPC 设备接入。

## 6.3.1 海康

海康 SDK 支持的设备型号：

### CVR

- **DS-A9 系列**：DS-A908RE-B 等；
- **DS-A71 系列**：DS-A71024R、DS-A71036R、DS-A71048R、DS-A71072R 等；
- **DS-A72 系列**：S-A72024R、DS-A72036R、DS-A72048R、DS-A72072R 等；
- **DS-A80 系列**：DS-A80216S、DS-A80624S、DS-A80636S、DS-A80648S 等；
- **DS-A81 系列**：DS-A81016S、DS-A81116S 等；
- **DS-A82 系列**：DS-A82012D、DS-A82024D、DS-A82060D 等。

### NVR

- DS-9600 系列；
- DS-9500 系列；
- DS-7700 系列；
- DS-7600 系列。

## 6.3.2 大华

大华 SDK 支持的设备型号：

### EVS

- EVS5016 / 5024 / 5036 / 5048 系列；
- EVS7024 / 7036 / 7048 / 7064 / 7072 系列；
- MCS7024。

### NVR

- NVR4832-4KS2；
- NVR4832；
- NVR3XX；
- NVR5XX；
- NVR724-256 等。

## 6.3.3 宇视

宇视 SDK 支持的设备型号：

### NVR

- NVR301 系列、NVR302 系列、NVR304 系列；
- NVR508 系列、NVR716 系列、NVR502 系列；
- NVR504 系列；
- NVR-B100 系列、NVR-B200 系列、NVR-B300 系列、NVR-B500 系列；
- NVR-S200 系列、NVR-S300；
- NVS-B200 系列。

### 一体机

- VMS-B200-A16；
- VMS-B180-A；
- VMS-B230 系列产品；
- VMS-B260 系列产品。
