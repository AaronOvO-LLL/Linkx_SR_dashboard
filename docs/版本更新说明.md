# 版本更新说明

> 早期项目没有统一的工作台版本号，以下按现有记录的日期整理；产品自身版本号不等同于工作台版本号。

**后续规划**

- 提供各产品 ASR 热词表，减少手工调整修改
- 完善文件归档功能，确保数据不丢失
- 日志系统更新，确保可以回溯访问出错


**v0.4.0　2026-10-27｜增加管理权限账号，便于开展账号管理**

- 管理员登录后可在导航栏进入「用户管理」。
- 显示注册用户总数、用户名、注册时间、创建项目数量。
- 支持普通用户、分部管理员、系统管理员三种角色。
- 分部管理员仅查看本分部项目和用户，管理本分部普通账号。


**v0.3.2　2026-10-25｜excel输出方式更新，设备管家、消防管家、安全管家字段更新**

- 所有踏勘结果可以通过excel形式导出。
- 更新设备管家导入方式，根据踏勘情况自动配置传感器数量。
- 根据消防COE舒文意见修改更新消防管家字段。
- 根据意见优化安全管家可通过SDK接入的设备内容，可自行确认对接设备类型，方便填写NVR或CVR的设备信息。

**v0.3.1　2026-10-21｜自助注册与项目范围选择**

- 登录页增加“注册”入口，填写姓名、电话（手机号）、分部即可注册普通个人账号。手机号作为登录账号，初始密码为 `onewo123`，注册页和成功提示均说明进入系统后可自行修改。
- 个人新建项目可选择“私密：仅创建者和管理员可以访问”或“分部共享：维持原分部权限”，默认私密。两种项目均记录真实创建者；已有项目范围不自动更改，复制仍默认创建个人私密副本。

**v0.3.0　2026-10-21｜个人账号与私密项目**

- 新增个人账号登录。管理员可创建、编辑、停用/启用账号并重置密码；用户可以修改自己的密码。
- 系统管理员可以跨分部查看项目；普通用户仍可使用本分部历史共享项目。原分部入口保留，只能访问分部共享项目，不能访问个人私密项目或管理账号。
- 历史项目不自动归到任何个人名下，明确显示「历史项目（未记录个人创建者）」。

**v0.2.0　2026-10-20｜项目公共资料共享、资产管家与聊天入口**

- 「项目基本情况」「物业信息」按项目统一保存；同一项目内一次填写，其他管家刷新即可读取，新添加的管家也能复用已有资料。各管家的专属答案和必填要求仍独立管理。
- 项目来源统一支持内部、外部、渠道、重点四项，保留历史含义。资产管家仅共享它已引用的项目名称，不增加额外物业表单。
- AI 仅补充空的公共字段，不覆盖已有公共答案；跨管家人工确认保护与写入在同一事务中完成。
- 新增资产管家，支持 14 项客户调研信息、8 项必填校验、北京时间提交时间、手填及文字稿提取，并可生成 Markdown/HTML 客户调研结果和 ZIP。最终方案类材料及报价能力尚未定义。
- 新增「姜子牙」聊天入口，支持文字对话、收起、切换页面继续等待回复和新对话。聊天使用独立会话，不自动读取或修改项目表单；记录保存在单个服务进程内存，重启后清空。
