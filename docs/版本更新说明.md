# 版本更新说明

> 早期项目没有统一的工作台版本号，以下按现有记录的日期整理；产品自身版本号不等同于工作台版本号。

**v0.2.0　2026-10-20｜项目公共资料共享、资产管家与聊天入口**

本版工作台版本为 v0.2.0，页面页脚和使用说明同步显示该版本。各管家的产品版本、字段模板版本独立维护。

新增与改进：

- 「项目基本情况」「物业信息」按项目统一保存；同一项目内一次填写，其他管家刷新即可读取，新添加的管家也能复用已有资料。各管家的专属答案和必填要求仍独立管理。
- 项目来源统一支持内部、外部、渠道、重点四项，保留历史含义。资产管家仅共享它已引用的项目名称，不增加额外物业表单。
- AI 仅补充空的公共字段，不覆盖已有公共答案；跨管家人工确认保护与写入在同一事务中完成。
- 公共资料变更后，旧校验不再作为当前通过依据；旧材料提示「公共资料已更新，需重新生成」，在线查看、下载和 ZIP 打包统一检查公共资料版本。生成或打包期间发生公共资料变更时，也不会把旧结果登记为最新可用结果。
- 新增资产管家，支持 14 项客户调研信息、8 项必填校验、北京时间提交时间、手填及文字稿提取，并可生成 Markdown/HTML 客户调研结果和 ZIP。最终方案类材料及报价能力尚未定义。
- 新增「姜子牙」聊天入口，支持文字对话、收起、切换页面继续等待回复和新对话。聊天使用独立会话，不自动读取或修改项目表单；记录保存在单个服务进程内存，重启后清空。
- 优化工作台标识和页面展示；设备管家核对页修复字典 `items` 被识别为方法而导致的 500 错误；使用说明页从本文件读取更新内容。

升级操作：

1. 停止旧版工作台服务，更新代码并重新启动。不要让新旧版本同时写同一个数据库。
2. 启动后自动执行数据库 v4 迁移。含历史答案的数据库会先通过 SQLite 一致备份生成 `workbench/data/workbench.db.pre-shared-v4.bak`；自定义数据库路径的备份位于其同目录，已存在的备份不会被重试覆盖。
3. 只有一份非空答案或各管家答案相同的，自动提升为共享答案；答案不同的，填报页列出原管家、答案和依据，用户选择一份或重新填写后共享。原记录、候选快照与确认结果保留。
4. 历史冲突未解决前，引用该字段的管家不能生成材料。公共资料提升为共享版本后，相关旧材料需要重新生成。
5. 使用姜子牙需配置 `GC_APP_ID`、`GC_SECRET_KEY`、`GC_BOT_ID`，其他可选配置见 `workbench/.env.example`；未配置时不影响项目填报和材料生成。

验证与已知限制：

- 五个产品配置检查通过；全量单元测试 101 项中 100 项通过，三组 Edge 浏览器回归通过，覆盖真实自动保存、跨管家刷新共享、冲突确认、清空、模式切换和手机布局。
- 剩余 1 项失败来自既有能源样例的设备名称与当前候选项不一致（如「冷水主机」与「制冷主机」），本版未改写其业务口径。使用当前候选项完成能源管家的共享资料、校验及 Excel 生成已另行测试通过。
- 本版材料版本保护针对项目公共资料；管家专属字段、模板和规则的完整版本追溯仍需后续完善。公共资料变更前的文件会保留到重新生成；生成目录仍沿用原有文件命名，不能视作完整的历史文件归档功能。
- 本机已有数据库的副本升级演练通过，原答案保留、待确认差异可见，全部已有管家的核对页正常。测试未修改业务数据库，未调用收费模型或转写接口，也不代表线上服务已经部署升级。

详细说明见 docs 目录：`项目公共资料共享_实现与验证_2026-10-20.md`、`资产管家_字段与流程接入说明_v1.md`、`姜子牙聊天接入说明.md`。
