# 灵石渠道商业化平台：2026 Q4 产品与协作规划

日期：2026-10-07。性质：供内部讨论与立项的建议稿，不代表公司已批准的商业政策、测算口径或资源承诺。

## 1. 产品判断与年底目标

长期方向：把公司的产品知识、方案经验与交付标准沉淀成平台，使渠道能够独立完成标准机会的识别、踏勘、初步配置、商业价值说明与交付提资，公司专家集中处理例外和关键承诺。

年底交付目标：在一个明确的产品和客户场景中，完成真实渠道可用的受控试点版本。新手经短时入门后，能按提示采集事实，生成可追溯的方案、成本及收益测算、交付资料，获得自动评审反馈，并提交给指定负责人确认。用真实项目证明独立完成率、专家工时和交付返工的改善。

这是商业化假设验证：降低每个合格渠道项目占用的总部资源，同时保持方案质量和项目经济性。界面、生成速度和模型调用次数是过程指标，不能单独证明商业模式成立。

本计划的执行假设：一名稳定投入的工程负责人，约半名工程/交互/测试支持，方案和交付专家每周各固定参与约两小时，渠道负责人提供三家试点合作伙伴。实际资源不足时缩减场景、模板和试点数量，保留完整业务流程。未经确认的资源均为建议。

## 4. 先选一个足够标准的场景

用以下维度评估安全、设备、能源三条候选线：真实商机可得性、方案标准化程度、价格/收益口径完备程度、现场信息是否易采集、交付负责人是否愿意验收。优先选资料和合作条件最成熟的一条，不能只按代码已有多少决定。

- 安全管家：现有材料链较完整。如果安保服务范围、岗位成本与公司报价口径可确认，可以作为优先候选。可核算岗位调整的成本变化，但需加入新增服务费用，区分理论节省与实际可兑现节省。
- 设备管家：规则清单基础较明确，适合检验新手踏勘与配置；当前不含价格、型号、线缆等完整成本，故清单生成不能直接等同于完整报价。收益缺乏可靠依据时，先出 TCO、覆盖范围和运维价值说明。
- 能源管家：收益表达直观，但当前实现是准入、设备与运行信息收集，没有完整节能模型。只有公司能提供基线、历史案例、工程测算和相应专家时，才适合成为 Q4 主线。

建议第一版定位为“有物业或现场常识、此前不熟悉公司产品的渠道人员”。让完全没有现场经验的人完成所有专业踏勘，需要额外培训与现场验证，不能在第一季度试点中默认成立。

## 5. Q4 必须贯通的流程

渠道入门 → 商机登记 → 场景选择与准入判断 → 引导踏勘 → 证据与字段确认 → 标准配置 → 成本/收益测算 → 自动预审 → 指定人员审批 → 对外方案与交付包 → 项目进展及返工反馈。

### 收资与新手体验

先询问现场事实与客户目标。例如“现在有多少岗位、覆盖哪些时段、有哪些监控与网络条件”，再推荐可适用的标准包。专业词配照片或示例，告诉用户怎么找、怎么问、为什么需要。允许“未知”，将未知转成补资料任务；只有到相应输出阶段才要求关键字段齐全。

原始照片、账单、图纸和录音能关联到字段证据即可，Q4 不必全部自动识别。先把可追溯、可核对做好。客户沟通材料优先做到可直接发送的 PDF 与可调整的文档；只在试点确有需要时增加更多格式。

### 产品规则与测算

产品包应定义适用条件、设备及服务组成、数量换算、客户配合事项、排除项和专家升级条件。产品负责人批准可卖内容，交付负责人批准可实施范围，商务负责人批准价格权限。

成本至少考虑设备、施工、集成、培训、服务及维护，并说明一次性与持续性费用。收益参数记录来源、确认人、计算期间、假设与版本；客户事实和公司经验假设分别标注。给出保守、基准、乐观情景，不能由模型随意填一个节省比例。

仅当收益与支出有可信口径时展示 ROI。对现金流大致稳定的项目，可报告“初始投入 ÷ 年净现金节省”的简单回收期；年净节省须扣除新增持续费用，非正数时不显示有限回收期。若需累计 ROI，应固定分析期限和纳入的全部成本，按批准的期间净收益与成本定义实现；首版没有必要强行加入复杂 IRR。

安全价值中的风险减少、设备故障概率降低应独立呈现。没有可靠概率、损失和基线数据时，不能把“避免一次事故的损失”作为必然现金收益。模型不足的产品输出价值说明或总拥有成本，不为了统一界面强行产生回报率。

### Agent 预审

第一版实现固定顺序的四类检查即可，无需多个自治 agent：

1. 收资检查：关键缺项、事实冲突、证据不足。
2. 配置检查：产品准入、组合及数量约束，成本完整性。
3. 商业检查：价格权限、测算期间、收益依据、重复计入与不合理承诺。
4. 交付检查：现场前提、接口、责任、施工及验收遗漏。

确定性规则处理数学、权限和硬约束；模型处理语言冲突、材料之间的遗漏和解释。评审项必须关联字段或材料位置，给出证据、严重度、修改建议和处理责任人。信息不足时报告未知。

先用十份专家认可的历史方案建立样本，包含故意植入的漏项和错误；保留部分未参与规则设计的案例做验证。观察重大问题漏检、误报和专家复核耗时。规则硬错误阻断提交；模型提示先由专家复核，避免未经验证的判断直接决定正式商业承诺。

发布时冻结项目事实、产品规则、价格、测算、模板及评审版本。后续更新另建版本，已发布材料能重现。现有“按最新规则重算”能力不能代替已对外方案的快照。

### 组织协作与试点运行

最小协作能力包括个人身份、渠道组织隔离、指定协作者、提交/退回/批准状态、评审备注和操作记录。渠道可见其授权项目与批准的价格，不默认获得内部底价及全部客户库。

沿用模块化单体、字段包、规则引擎和现有生成能力。Q4 优先补业务闭环；是否换数据库由实际并发、任务稳定性和恢复要求决定。试点前完成组织隔离、发布版本复现、异步任务重启恢复、备份恢复和完整主流程验证。

## 6. 与公司协作：每个角色承担具体产物

| 角色 | 决策与责任 | 第一阶段必须交付的产物 |
|---|---|---|
| 你／产品负责人 | 目标用户、场景、范围、优先级、体验与验收指标；推动跨部门决定 | 产品章程、用户流程、需求与决策记录、试点报告 |
| 业务赞助人 | 资源协调、部门冲突和阶段投资决策 | 书面确认试点目标、人员投入、阶段评审日期 |
| 方案／产品专家 | 产品适用边界、配置规则、经验收益假设 | 十份脱敏案例、标准产品包、例外清单、预审标准 |
| 商务／财务负责人 | 价格、折扣、成本与收益口径、合同承诺 | 受控价格表、完整成本项、测算规则、审批权限 |
| 交付负责人 | 实施前提、交付边界、接口和验收标准 | 合格交付包样本、漏项清单、验收检查表 |
| 工程负责人 | 技术方案、实现、运行稳定性、数据权限与上线质量 | 可用版本、必要验证、运维与恢复方案 |
| 渠道负责人 | 试点招募、商机保护、渠道利益和使用反馈 | 三家伙伴名单、试点约定、真实项目队列 |
| 渠道试点人员 | 实际操作、提交资料、反馈阻碍和客户进展 | 可观察的操作记录、真实项目资料与阶段反馈 |

同一人可以承担多个角色，但每类决定必须有一名最终负责人。你不必独自承担产品、财务口径、工程上线和所有方案责任；你需要把这些责任组织成可以运转的流程。

向专家请求“确认十个案例里的共性、例外和重大错误”，比笼统请求“提供一些专业知识”更容易获得有效投入。预审能力给专家减少重复工作；交付标准减少交付返工；渠道机制给伙伴更快反馈和明确收益。

至少落实五项试点机制：商机登记和保护期限、冲突解决负责人、渠道可赚取的利润/服务收入、总部反馈时限、伙伴可调整与必须审批的承诺。初期可以书面规则加人工台账执行，先验证再自动化。渠道品牌呈现及是否署名亦需明确。

建议与公司确认你的产品负责人身份、范围裁量权、命名的协作人员、阶段验收口径及成果记录方式。每周一次三十分钟决策会，议题是待定口径、真实用户阻碍和验收数据；双周用真实项目演示。需求、决定、里程碑和贡献持续留档，支撑年底对产品工作的评价。

## 8. 验收与商业模式证据

以下是建议目标，先以首批项目测基线再确认，不是行业平均值或确定性收益预测。

| 指标 | 口径与建议目标 |
|---|---|
| 新手独立完成 | 完成统一入门后，在规定场景内无专家现场代操作地提交完整资料；六名新手争取至少五名成功，记录求助次数和类型 |
| 内部售前工时 | 统计渠道项目所占用的方案、商务复核和交付咨询总工时，按相似规模项目对比基线；争取中位数下降至少 30%，防止把工作转移后误判为节省 |
| 初稿质量 | 首次专家评审无重大配置、金额或实施边界错误；争取达到 80%，小样本同时报告通过数/总数 |
| 交付接收 | 争取至少三个真实交付包被交付负责人接收，记录补资料轮次与关键返工 |
| 渠道持续使用 | 至少两家伙伴主动使用第二个项目；区分主动复用与由项目负责人催办 |
| 商业进展 | 跟踪合格机会、客户接受下一步、报价、签约等状态；争取至少三个真实机会进入明确下一阶段，年底不将所有机会签约作为平台唯一验收条件 |
| 平台运行 | 无已知严重越权问题；发布材料能复现；备份能恢复；主要异步任务与端到端流程验证通过 |

计时区分现场踏勘、实际操作、专家复核与等待时间。用相似场景和统一评审标准比较；样本可做初步决策依据，不能声称已经证明普遍因果关系。

商业模式先验证公司承担基础平台成本、伙伴低门槛使用、双方从产品/服务交易中获益的方式。伙伴获益可来自明确的转售差价、实施收入或持续服务收入；是否抽成或订阅收费，在验证活跃使用与实际价值后再决定。

单项目经济性至少记录：已实现收入、直接交付与服务成本、渠道收益、总部售前/复核成本和平台可变成本。只将签约且能兑现的贡献作为收益事实；对机会价值单独列示。专家工时节省作为产能改善，未必立即转化为现金成本减少，不能与新增收益重复加总。

年底证据包包括：一份产品章程；一套获业务、商务、交付认可的规则与模板；渠道独立操作录屏；真实项目及交付接收记录；对比基线的指标报告；渠道第二次使用记录；下一季度扩大或收敛的建议。它们共同证明你对产品、协作和商业模式的定义能力。
