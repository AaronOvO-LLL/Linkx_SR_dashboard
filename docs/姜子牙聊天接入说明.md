# 姜子牙聊天入口

登录任一分部后，所有工作台页面右下角均显示「姜子牙」按钮。点击展开对话框，
支持文字聊天、Enter 发送、Shift+Enter 换行、收起和新对话。聊天不会跳转页面，
不会自动读取项目资料，也不会修改表单。

## 运行配置

工作台通过 `providers/gc_agent.py` 调用 GC 单 Agent API，该模块复用命令行 MVP
当前已验证的调用逻辑，无需随生产部署携带 `agent_cli_mvp` 目录。

将 `GC_APP_ID`、`GC_SECRET_KEY`、`GC_BOT_ID` 配置到服务环境变量，或
`workbench/.env`。其余配置见 `workbench/.env.example`。优先级：系统/用户环境变量、
工作台 `.env`、本地开发兼容的工作区 `agent_cli_mvp/.env`（生产禁用此回退）、默认值。
当前沿用现有 `GC_USER_ID`，未接入工作台用户 ID 映射。配置不会送到前端。

默认 `GC_CONTEXT_MODE=client`，每次携带最近成功完成的最多 6 轮、12000 字符，
超过会在聊天框提示。此模式补偿平台原生上下文未生效的问题，并不修改平台系统提示词。
每条输入最多 4000 字，一段对话最多约 50 轮，达到上限后使用「新对话」。

## 会话与限制

- 每个浏览器登录会话独立维护上游会话及历史；同一登录的多个标签页共享聊天。
- 仅登录后的会话可访问聊天接口；写接口校验随页面发出的 CSRF token。
- 回复由后台线程取得，收起窗口、刷新或切换工作台页面不会中断后台请求。
- 记录只保存在服务进程内存；服务重启、退出登录、闲置超过 8 小时后清空。
  前端只在当前标签页的 sessionStorage 保存展开状态和输入草稿。
- 沿用现有单进程多线程部署；多个服务进程不能共享此聊天状态。
- 同一对话等待回复时禁止重复发送和新建对话；接口超时不自动重发，避免重复提交。
- 同一个 GC userId 下的不同 messageId 是本地实现的会话区分，平台对同一 userId
  的额外行为仍由平台决定；真实多人身份映射留待后续。
- Agent 回复作为纯文本展示，保留换行；不执行 HTML，不接入文件、语音或流式输出。

## 本地启动与检查

在 `workbench` 目录执行 `.venv\Scripts\python.exe app.py`，默认访问
`http://127.0.0.1:8770`。本次接入没有新增第三方依赖或修改业务数据库结构。

离线验证：`.venv\Scripts\python.exe -m unittest tests.test_agent_chat -v`。
