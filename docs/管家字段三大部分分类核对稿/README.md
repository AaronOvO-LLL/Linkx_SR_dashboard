**统一归类口径**

- 项目基础信息：项目概况、物业与服务信息、项目资料、决策地图、特殊要求；资产管家另将已有客户信息、填报记录及需求资料归入此区。
- 产品交付条件踏勘：设备与系统事实、网络和安装条件、软件部署条件、产品准入门槛、现场实施结论。
- 相关业务访谈：当前如何管理和运营、人员与协作关系、运行策略、业务目标与痛点、对落地有影响的产品商务事项。

**需要人工重点核对的边界**

- 公共分类与答案共享不是同一件事：当前项目概况、物业信息、决策人、甲方对接人按项目共享；资料、上线时间、预算、特殊要求仍由各管家独立保存。本稿不改变这一行为。
- 第一部分目前仍有产品差异：安全管家未使用“服务类型”；资产管家只使用公共项目名称，另保留原客户信息与资料字段。其他公共字段未擅自补入。各产品原有必填差异在正文中如实标注，是否进一步统一请人工核对。
- 消防管家的“套餐类型”暂放交付范围；恒益、卫士一次性改造费用暂放业务访谈下的商务落实。
- 能源管家的空调电费门槛属于经济准入，暂放交付条件；供冷范围与末端管理属于实际运营责任，放业务访谈。
- 安全管家的网络管理员放在接入条件，重点位置、事件和算法需求放在业务访谈。
- 资产管家的部署方式放交付条件，经营规模、数字化现状、增值服务需求放业务访谈。当前部分字段同时含技术和业务信息，先保留原字段，未拆分。
- 设备管家尚无独立业务访谈字段，第三部分保留待确认；不为凑齐分类虚构字段。
