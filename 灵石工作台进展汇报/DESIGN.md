## 1. 画布与全局母版

- **画布**：1280 × 720 px（16:9）
- **安全区**：Slide `padding: 20px 64px`（上下 20 / 左右 64），绝对定位仅用于背景装饰，不得挤占安全区
- **母版三区（px 硬值，逐页复用）**

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 20–128px | 108px | kicker（14px，primary，letterSpacing 2）+ 主标题（34px bold, ink）；标题块右侧留空，禁止塞装饰小图 |
| **B · 内容区** | 128–652px | 524px | 全部正文 / 图示 / 卡片；禁止挤占 A / C 区 |
| **C · 页脚条** | 652–700px | 48px | 左侧「灵石解决方案工作台 · 进展汇报」（14px 灰）+ 右侧页码 `NN / 12`（14px 灰） |
| 合计 | 20 + 108 + 524 + 48 + 20 = **720px** | ✅ 不溢出 | |

封面（01）与结束页（12）**省略 A/C 区**，采用全幅自定义版式；02–11 严格复用三区。

## 2. 颜色系统

**色彩池（4 hex，含中性色）**

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| **主色 primary** | `#2F5597` | 左侧标题栏底色、架构图主区块、流程节点、页脚分隔线；取自应用本身配置的品牌色 `brand_color: #2F5597`，与产品界面同源 |
| **辅色 support** | `#E8EEF7` | 卡片底色、表格斑马纹、图示浅底区块 |
| **强调色 accent** | `#E2703A` | 只出现在焦点元素：巨型数字、待决策条目的左侧标记、关键约束标签；**占比 ≤ 10%** |
| **中性 ink** | `#1F2937` | 正文、标题、页脚 |

- 画布底色 `#FFFFFF`（视为画布而非色彩池成员）。次级文字统一用 `rgba(31,41,55,0.62)`，反白文字用 `#FFFFFF`，均为 ink / 白 的透明度派生，不引入新 hex。
- **禁止**在同一页出现 ≥2 套主色板；禁止高饱和撞色铺满 ≥1/3 页面。

**2.1 色彩面积分配（页面映射表已逐页声明）**

| 色彩角色 | 常规页上限 | 说明 |
| :--- | :--- | :--- |
| 主色 | ≤ 60% | 左侧标题栏 / 图示主体 |
| 辅色 | ≤ 30% | 卡片底、斑马纹 |
| 强调色 | ≤ 10%（Hero / peak 页可至 15–20%） | 巨型数字、决策标记 |
| 中性 | 剩余 | 文本、页脚、边框 |

**2.2 渐变与半透明**
- 唯一渐变：`linear-gradient(135deg, #2F5597 0%, #24406F 100%)` —— *注意：为守住 4 hex 上限，本项目的深色面板统一使用**纯色 `#2F5597`**，不使用渐变。封面图压暗层用 `linear-gradient(90deg, rgba(47,85,151,0.92) 0%, rgba(47,85,151,0.35) 100%)`（primary 的透明度派生）。*
- 半透明白卡叠在图上：`rgba(255,255,255,0.94)`（封面文字卡）。
- 卡片浮起：`boxShadow: '0 4px 20px rgba(47,85,151,0.10)'`（仅用于 3 处以内，避免全篇浮起）。

## 3. 字体系统

**字体家族（1 套，标准要求 ≤2）**：`Microsoft YaHei`

> 选型理由：本汇报要在多台电脑（含会议室机与笔记本）上直接放映，优先保证中文渲染零缺字；家族数量少也更利于全篇一致。字重与字号的阶梯对比承担全部层次区分。

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 76px | bold | 1.15 | -1 | 仅封面 |
| 章节 / 收束大字 | 60px | bold | 1.2 | 0 | 封面副标、结束页 |
| **巨型数据／锚点** | **104px** | **bold** | **1.0** | **-2** | 04「2 分钟」、10「¥12–32」 |
| 次级锚点数字 | 34px | bold | 1.1 | 0 | 巨型数字周边的对照数据 |
| 页面主标题（A 区） | 34px | bold | 1.3 | 0 | 每页固定 |
| kicker（A 区上沿） | 14px | bold | 1.3 | 2 | 每页固定，primary 色 |
| 卡片小标题 / 条目标题 | 22px | bold | 1.4 | 0 | 卡片头、表格表头 |
| 正文 | 18px | regular | 1.65 | 0 | 段落、条目 |
| 辅助说明 / 引文 | 15px | regular | 1.55 | 0 | 图注、约束标签 |
| 页脚 / 页码 | 14px | regular | 1.4 | 0 | C 区 |

- 巨型数字与相邻正文的**字重差 ≥ 2 档、字号差 ≥ 4 倍**。
- 正文行长控制在单栏 46–52 个中文字符内；条目行距 ≥ 14px。

## 4. 信息密度门禁（沿用通用默认值）

| 页面类型 | 最少元素 | 正文字数下限 | 图数下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标题+副标+主视觉 | 20 | 1 | ≥ 35% |
| 内容页 · 单主题 | 标题+正文+主视觉 | 180 | 1 | ≥ 30% |
| 内容页 · 条目组 | 标题+引导句+N 条 | 合计 ≥ 300（3 条时） | 0–N | — |
| 数据 / 巨型数字页 | 标题+主图+洞察 | 80 | 1 主图 | ≥ 50% |

- **留白上限**：常规内容页 ≤ 35%；04 / 10 允许 30–33%（围绕巨型数字）；01 / 12 允许 35–40%。
- **容器填充率 ≥ 85%**：卡片内尾部元素（结论条 / 标签）必须 `marginTop: 'auto'` 钉底，禁止悬浮中段。
- **横向兄弟条对齐**：同一组条目块的「标题 / 正文 / 标签」三段 y 轴等高。

## 5. 配图系统

| 等级 | 用途 | 出现位置 | 接入方式 |
| :--- | :--- | :--- | :--- |
| **L1 · 主视觉** | 承担页面主要叙事 | 01 封面（全幅铺底）、06 架构图（占 B 区 58%）、09 拓扑图（占左栏 62%） | `ImageGen` / 内联 `<svg>` |
| **L2 · 支撑图** | 强化段落 | 07 流程带（占 B 区 46%） | 内联 `<svg>` |
| **L3 · 母版徽标** | 全篇统一角标 | 05–11 页 B 区左上 12×12 圆点（primary，opacity 0.5） | 纯色块，位置全篇一致 |

**配图获取**
1. 唯一天然具象场景 = **封面**：`ImageGen` 生成 `assets/cover_control_room.png`（关键词：现代化园区安防监控中心 / 运营指挥室大屏 / 冷色调 / 摄影 / 无人 / 无文字）。
2. 架构图、拓扑图、流程图、巨型数字、阶梯条、流程带等**结构化低语义元素一律用内联 `<svg>` 或 `<Box>+<Text>`**（依据 `component-diagram.md` 硬规则：默认走 SVG，`<Diagram>` 仅作兜底）。
3. 全篇 L1 风格统一为「冷色调实拍 + 线性矢量图」，不做插画 / 3D 混搭。
